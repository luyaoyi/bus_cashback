# 汽车票复购返现后台原型

这是基于现有“真车主完单返现”后台页面结构制作的简版原型，包括活动配置管理、新建活动和参与数据三个页面。

开发与测试请对照[复购返现后台原型说明](./复购返现后台原型说明.md)核对页面字段、操作和边界；跨系统业务规则另见[需求文档](./汽车票二单返现需求文档.md)。

## 页面

- `activity-list.html`：查询活动；支持查看、编辑、日志、复制，并可进入新增页。
- `index.html`：共用的新建、查看、编辑、复制配置页；保存后写入浏览器本地数据，并返回配置管理页。
- `participation-data.html`：按用户、订单、活动及状态查询参与记录，查看资格、发券和分次返现明细；可演示单期奖励强制流转。

## 新建活动模块

- 基础信息：活动名称、必选渠道、优先级（1～9999 的整数）、投放时间和状态；活动 Code 保存时自动生成。
- 投放限制：可选产品 Tag、AB 实验分组，选中后展示对应配置；产品 Tag 整段输入最多 100 字符。次数限制单独配置，可选每人每月参与次数。
- 二单资格配置：资格有效时长（输入时限制为 1～999 的整数小时）、礼包名称（必填，1～10 个字符）、礼包说明（必填，1～100 个字符）、礼包价值（必填，1～999 的整数）、礼包发券活动。
- 返现配置：返现金额上限为 1～500 的整数，右侧显示中文金额；需再次输入相同金额确认后才能保存，并配置营销返现金活动。
- 分次领取配置：新建时显示 3 期空白配置，支持 1～5 期；单期比例为 1～100 的整数且合计 100%；领取开始和结束时间为 0～99 的整数天，以第二单出行时刻为基准、按连续 24 小时计算。
- 前端展示配置：非必填的单行弹窗活动文案（最多 100 字符）、富文本规则说明；规则说明支持基础文字格式与列表。

## 已实现交互

- 产品 Tag 实时解析预览、去重及空值校验。
- 投放限制按产品 Tag、AB 实验分组勾选联动。
- 渠道限制多选及至少选择一项校验。
- 分次奖励动态增删。
- 分次比例合计 100% 校验。
- 每期领取时间范围校验，允许时间重叠。
- 按返现上限生成金额拆分示例。
- 表单必填项及主要数值范围校验。
- 保存的新活动可在“活动配置管理”页面查询。
- 活动列表“查看”进入与新建共用的配置表单页，回填该活动配置；全部控件只读、隐藏保存按钮，可返回列表。
- 活动列表“编辑”允许修改有效活动，保留原活动 Code；修改只影响后续新参与，已有资格和奖励使用原配置快照（次数限制仍按既定实时口径）。
- “复制”预填原活动配置、投放时间和状态，活动名称追加“复制”；保存时生成新 Code。“日志”展示创建、编辑、复制记录及编辑前后值；历史示例活动无记录时显示“暂无日志”。原型操作人标为“原型操作员（演示）”，日志仅保存在当前浏览器。
- 在参与记录详情中，对未同时达到“领取成功、打款成功”的单期奖励，可二次确认后执行“强制流转”；操作时间和状态保存在浏览器本地。此原型不发起真实领取或打款，审计和资金核对要求见需求文档 5.1 与 5.2 第 12 项。
